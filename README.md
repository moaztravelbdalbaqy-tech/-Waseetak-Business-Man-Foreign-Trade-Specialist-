# موقع وسيطك — رفع على GitHub Pages

1. أنشئ Repository جديد على GitHub (مثال: `wasitak`) وخليه Public.
2. ارفع كل الملفات والمجلدات كما هي: `index.html` و `css/` و `js/` و `.nojekyll` و `README.md`.
3. من Settings ← Pages ← Source: Deploy from a branch ← Branch: `main` و Folder: `/ (root)` ← Save.
4. بعد دقيقة أو اتنين الموقع يظهر على: `https://USERNAME.github.io/wasitak/`

## التعديل
